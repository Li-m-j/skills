## 9. 法律约束与合规

### 9.1 数据来源合规

| 数据源 | 协议 | 使用范围 |
|---|---|---|
| **arXiv Export API** | 官方公开 API，须遵守礼仪限速（1 req/3s） | 元数据可存；全文仅链接到 arXiv 官方 PDF，按**单篇 license**（CC BY / arXiv 非独家分发等）使用 |
| **OpenAlex** | CC0（公有领域） | 可自由使用、修改、分发，无需署名（建议注明 "Data from OpenAlex"） |
| **Crossref** | CC0 | 同上 |
| **Semantic Scholar** | API 协议 | 注明来源；仅限非商业用途，遵守其 Terms of Service |
| **SSRN / NBER / RePEc** | 无公开 API | 仅人工跳转原页；不抓取、不入结构化字段（除非其论文已被上述合法源收录） |

### 9.2 引用规范

- **必须保留**：原始作者、期刊、DOI / arXiv ID、出版商信息
- **必须输出**：4 种引用格式（BibTeX / APA 7 / GB/T 7714 / RIS），按学术规范
- **工作论文**：引用格式必须体现未出版状态（`[Preprint]` / `working paper` + 编号或 arXiv ID）；**严禁**把工作论文渲染为已同行评审的正式发表
- **同一论文有预印本与正式版时**：引用以正式版为口径，预印本仅作为 OA 获取途径注明
- **严禁**：去除作者署名、期刊信息、DOI
- **翻译字段**（GB/T 7714 中文版）：由 LLM 拼装，**不作为权威引用**，仅供中文用户参考；以英文原版为准
- **档位表口径**：`se_journal_tiers.json` 是**编辑共识的分层惯例**（经济 Top5 / 统计四大 / 金融 Top3 / 中文权威），非官方分级、不含影响因子；向用户呈现时不得包装成权威排名

### 9.3 内容使用边界

**允许**：

- 保存论文元数据（标题、作者、DOI、arXiv ID、摘要、引用数、概念标签）
- 保存 inverted index 还原的 abstract
- 复制 OpenAlex concepts（CC0）
- 通过 DOI / arXiv 链接到出版商或 arXiv 原页（仅作跳转）
- 链接到 arXiv 官方 OA PDF（不镜像存储批量全文）

**禁止**：

- ❌ 存储付费墙后的 PDF 原文
- ❌ 批量下载/镜像出版商数据库或 arXiv 全站
- ❌ 商业转售聚合数据
- ❌ 去除来源标识
- ❌ 用于生成假论文、伪造数据
- ❌ **挑选性引用**：只保留支持预设结论的文献（计量研究语境下属实质性学术不端；名录必须按检索事实完整交付，方向过滤只能基于主题相关性）
- ❌ 替代人工阅读原文作为决策唯一依据

### 9.4 领域红线（统计/经济学专属）

- **不构成投资建议**：输出为文献名录，不含任何"利好/利空/买卖"判断；用户据此交易的后果自负，Agent 应拒绝把检索结果改写成投资建议。
- **不替代官方统计发布**：涉及 GDP、CPI、就业、货币口径等，只检索研究文献；数值一律指向国家统计局 / BEA / FRED / 央行等**原发布方**，本 skill 不缓存、不改写官方数值。
- **政策敏感性**：检索结果涉及未公开数据处理、监管博弈等敏感议题时，仅罗列文献事实，不输出政策效果判断或立场性评论。
- **研究伦理**：涉及人类subjects实验（RCT、田野实验）文献的元数据可存；不复制论文中的个体级数据。

### 9.5 隐私与个人信息

- 不存储用户搜索历史到云端
- `seen_papers.json` 仅存 DOI / 标题哈希（公开标识符）
- `user_prefs.json` 存本地路径，不上传
- `api_keys.local.json` 存本机，仅 skill 内部使用
- ❌ 严禁分享他人提供的 API key
- ❌ 严禁把用户搜索内容上传到第三方

### 9.6 学术道德

- 本 skill 是**辅助工具**，不替代人工阅读
- 检索结果仅供学术调研，**不作为决策唯一依据**
- 引用必须以**原文献**为准，本工具输出仅作辅助
- 严禁用于：代写论文、伪造数据、剽窃、p-hacking 式挑选文献、学术不端
- 严禁绕过付费墙抓取全文
- 严禁批量爬取造成出版商 / arXiv 服务器压力（arXiv 违规可能被封 IP）

### 9.7 适用法律

- 本 skill 仅在用户所在司法辖区**合法使用**
- 涉及跨境学术资源时遵守当地法规：
  - **中国境内**：遵守《网络安全法》《数据安全法》《个人信息保护法》《科学技术进步法》
  - **欧盟**：遵守 GDPR
  - **美国**：遵守 CFAA、DMCA
- 学术出版商协议以各出版商 ToS 为准（经济金融类多为 Wiley/Elsevier/Oxford/University of Chicago Press）
- 如发现违规使用，立即停止相关功能
