# paper-deep-reading — 评测清单（eval suite）

> 用途：让"改一行 SKILL.md / 模板 / 脚本是否变好或变坏"可被**观察到**。
> 对应 `skill锐评.md` 的第 13 条（"完全没有 eval（最严重）"）。
> 任何改动 SKILL.md / 模板 / 脚本之后，跑一遍下表并把结果追加到 `_eval/YYYY-MM-DD.md`。

---

## 一、Gold standard 论文集（10 篇 · 覆盖各类分支）

> 目的：覆盖"原创 / 综述 / 观点 / 快报 / 扫描件 / 英文 / 中文 / 长篇 / 短篇 / SI 缺失"十种情形。
> 论文可用用户自备 PDF 替换，但**类型分布要保持**。

| # | 类型 | 说明 | 主要考察 |
|---|---|---|---|
| G1 | article（短，≤8 页） | 常规计算化学论文 | 7 模块 10 要点齐全；总结 250-400 字 |
| G2 | article（长，>20 页） | 如 JACS / JCTC 长文 | 要点 4 能选出后段的关键性能图；总结 500-800 字 |
| G3 | review | 综述 | 自动切 5 模块 8 要点变体 |
| G4 | perspective | 观点文 | 要点 1 为"作者立场"；要点 6 含"立场偏向" |
| G5 | account | Accounts 类 | 要点 2 为"课题组方法演进" |
| G6 | letter / communication | 快报 | 精简版（1500-2500 字） |
| G7 | editorial | 社论 | 自动转速览模式并说明 |
| G8 | 扫描件（无文本层） | 图片型 PDF | 触发 OCR 兜底分支 + `ocr:<引擎>` 标注 |
| G9 | 中文论文 | 中文期刊 | 章节定位（中英混排标题）正确 |
| G10 | SI 缺失 | 正文提到 SI 但未提供 | 要点 9 标注"SI 缺失，仅依据正文" |

---

## 二、A 组 · 硬性正确性（必须 100% 通过）

| # | 检查项 | 判定方式 |
|---|---|---|
| A1 | 脚本可运行 | `python -m py_compile *.py extractors/*.py` 全通过；`pdf_extractor.py --help` 正常 |
| A2 | 结构完整 | 报告含全部 10 个要点（article）或 8 个（review 变体），编号无重复无跳号 |
| A3 | 无幻觉数值 | 随机抽 5 个数值，均能在 `full_text` 中检索到 |
| A4 | 覆盖度声明存在 | 含 `extractor_used` / `page_count` / 章节定位 / `paper_type` / SI 状态 |
| A5 | 图片真实 | 要点 4 每张图的路径都存在于 `key_images` 返回列表中 |
| A6 | CI-NEB 技巧 | 报告提到 `CI-NEB` 时译名与主表一致（"爬坡图像微动弹性带"） |
| A7 | 三色标注 | 【原文】/【AI分析】/【推测】均出现且使用位置合理 |

## 三、B 组 · v0.4 新能力（应通过）

| # | 检查项 | 判定方式 |
|---|---|---|
| B1 | paper_type 枚举 | 用 G3/G4/G5/G6/G7 分别跑，`paper_type` 输出与预期一致 |
| B2 | 报告分支正确 | G3→5 模块 8 要点；G7→速览；G6→精简 |
| B3 | 用户可覆盖 | 说"这不是综述"后，报告按 article 生成 |
| B4 | 图片选取理由 | 要点 4 每张入选图都有"选取理由"；末尾有"未选用候选" |
| B5 | 后段关键图 | 对 G2，选中的图不全在前 5 个 figure 内（验证"不再机械取前 5"） |
| B6 | 总结字数 | G1 落在 250-400；G2 落在 500-800 |
| B7 | 软件许可清单 | 要点 9 按 5 组输出并覆盖论文实际用到的全部软件/数据库 |
| B8 | OCR 兜底 | 对 G8，输出 `ocr_hint` 并给出可复制命令，而非仅"请自行 OCR" |
| B9 | 溯源解析 | 元信息块含通讯作者/单位/基金号（G1 无致谢时应写"原文未提供"） |
| B10 | 术语优先级 | 主表与参考表冲突时取主表（用 "transition state" 验证，不出现"中间态"） |

## 四、C 组 · 回归诊断

| # | 检查项 | 判定方式 |
|---|---|---|
| C1 | 图片候选池 | `key_images` 条数 ≤ 12 且按正文顺序（`--images-sort position` 默认） |
| C2 | 无 PyMuPDF 降级 | 卸载/屏蔽 fitz 后 `key_images` 为空且报告写"图片未提取"而非报错 |
| C3 | 速览模式 | "快读"触发 ≤500 字且保留反幻觉 + 覆盖度声明 |
| C4 | IMA 独立性 | 未配置 IMA 时，PDF 输入全流程不受影响（不加载 ima-integration.md） |
